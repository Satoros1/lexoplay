Первая сборка LexoPlay: перевод реплик в играх по F2.

**Как запустить**
1. Скачай `LexoPlay.exe` ниже и запусти. Windows может предупредить про неизвестного издателя: «Подробнее» → «Выполнить в любом случае».
2. В настройках вставь свой ключ Anthropic (вкладка с ключом откроется сама).
3. Открой игру, нажми Ctrl+Shift+F2 и выдели мышкой окно диалога, Enter.
4. F2 переводит реплику, F4 прячет перевод, Ctrl+F2 выделяет окно диалога заново.

Игра должна быть в окне или окне без рамки. Маленькие игры (800×600) растягивай через Magpie, LexoPlay это поймёт сам.

Связка с Lexo (перевод без своего ключа, слова в карточки по F3) придёт в 0.2.0.
