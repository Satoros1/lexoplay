Перевод заработал и стал быстрее, шрифт окна чёткий.

**Перевод**
- Исправлено «Модель ответила непонятно». Claude Haiku 5.5 по умолчанию сначала «думает», и это съедало лимит ответа до самого перевода. Теперь размышления выключены: ответ приходит сразу.
- Модель отвечает просто переводом, без JSON, поэтому разбирать её ответ больше не нужно.
- Перевод появляется по словам, пока модель его пишет, а не целиком в конце.
- Соединение с сервером перевода открывается заранее, пока LexoPlay читает текст с экрана.
- Реплики капсом (пиксельные шрифты, как в Hotline Miami) переводятся обычным регистром.

**Окно**
- Шрифт окна теперь системный Segoe UI Variable: чёткий при любом масштабе экрана, заголовки и подписи жирнее.
