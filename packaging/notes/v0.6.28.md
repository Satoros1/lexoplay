Сохранённые слова больше не находятся в чужих словах.

- «number» больше не считается формой «numb», «corner» формой «corn», «morning» формой «morn» и так далее. Форма засчитывается, только если это правдоподобно: частое слово само по себе остаётся собой, а не превращается в редкое с отрезанным окончанием.
- Настоящие формы узнаются как раньше: numbed и numbing для numb, happier для happy, bigger для big, quickly для quick, eerily для eerie, stuck для stick.
- То же самое и для жёлтого подчёркивания в F3.

Обновление встанет одной кнопкой: окно LexoPlay → «Обновить».
