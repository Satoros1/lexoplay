# LexoPlay

Перевод реплик в визуальных новеллах и играх по клавише. Захватывает окно диалога,
распознаёт английский текст встроенным Windows OCR и показывает над ним одну строку
перевода. Вокруг игры ничего не рисует. По F3 слова реплики уходят в Lexo карточками,
с репликой из игры как примером.

Полная техспека: документ «LexoPlay: техспека». Клиент ходит только в `/desktop/*` сервера
Lexo по токену устройства; без привязки F2 работает своим ключом Anthropic.

## Как пользоваться

1. Скачай `LexoPlay.exe` из Releases и запусти. Откроется окно LexoPlay, значок останется в трее у часов.
2. **Lexo**: введи код привязки (в боте `/link` или в Mini App «Профиль → Подключить ПК»). Без Lexo можно
   вставить свой ключ Anthropic во вкладке «Ещё», тогда работает только перевод.
3. **Игры → Добавить игру**: запусти игру и выбери её окно из списка. LexoPlay сразу покажет стоп-кадр
   игры: обведи мышкой окно диалога и нажми Enter. Tab переключает на необязательную рамку для имени.
4. Дальше в игре:

| Клавиша | Что делает |
| --- | --- |
| F2 | перевести текущую реплику; ещё раз F2 спрятать |
| F3 | режим слов: клик по слову, «+» или Enter сохраняет; Shift+клик выбирает фразу; Esc выход |
| F7 | разбор реплики: сленг, идиомы, трудные места; каждый пункт можно сохранить в слова |
| F4 | спрятать перевод (и остановить автоперевод) |
| F6 | выделить окно диалога заново и перетащить плашку перевода, куда удобно |

Пока открыт режим слов или разбор, клики и колесо мыши до игры не доходят: реплика случайно не
пропустится. Клик по пустому месту просто закрывает режим.

Вкладки окна: «Игры» (что прочитано в окне диалога и каким способом), «История» (все переводы,
повтор реплики переводится бесплатно из неё), «Слова» (экспорт для Anki), «Прогресс» (реплики, слова,
время по дням, цель на день), «Вид» (размер, место и шрифт перевода, автоперевод), «Ещё» (свой ключ,
автозапуск, обновление в один клик).

Клавиши меняются во вкладке «Клавиши» (одна клавиша или сочетание из двух). Они работают, только пока
игра на экране; в браузере и других программах F2 и остальные ведут себя как обычно.

В режиме слов подчёркнуты слова реплики: пунктир = нового слова в Lexo ещё нет, жёлтая линия = уже есть.
Карточка слова встаёт над окном диалога и строкой перевода, ничего не закрывая. Слова уходят в колоду,
выбранную для игры во вкладке «Игры» (по умолчанию своя колода с названием игры). Добавленные слова сначала
ложатся в локальную очередь и уходят в Lexo сразу или, если нет сети, позже сами.

Перевод и режим слов никогда не забирают фокус у игры. Выделению окна диалога фокус нужен, поэтому
оно рисуется поверх стоп-кадра, а после Enter игра разворачивается обратно.

**Маленькие игры (800×600) на большом мониторе.** Растяни игру через [Magpie](https://github.com/Blinue/Magpie):
LexoPlay сам видит, что игра растянута, и рисует строку на растянутой картинке.
Старые игры в эксклюзивном полноэкранном режиме переведи в окно (dgVoodoo2 / DxWnd).

**«Нет английского OCR».** LexoPlay предложит установить пакет одной кнопкой
(PowerShell от администратора, около минуты). Вручную:
`Add-WindowsCapability -Online -Name 'Language.OCR~~~en-US~0.0.1.0'`.

Логи и настройки: `%APPDATA%\LexoPlay\` (`lexoplay.log`, `settings.json`, `local.db`).
Галочка «Сохранять кадры» во вкладке «Ещё» (или запуск с `--debug`) кладёт в `debug\` кадр, картинку для
OCR и распознанный текст. «Ещё → Собрать отчёт об ошибке» упаковывает всё это в zip на рабочем столе.

## Разработка

```bash
pip install -e ".[dev]"
pytest -q                       # чистая логика и UI (offscreen), работает и на Linux
python -m lexoplay --debug      # запуск (только Windows)
python -m lexoplay --selftest   # самопроверка Windows-части: OCR, захват, оверлей, хоткеи, keyring
```

Каждый push собирает exe на `windows-latest` (GitHub Actions): тесты, самопроверка из исходников,
сборка PyInstaller, самопроверка уже собранного exe. Самопроверка гоняет и настоящий `App`
с поддельным сервером Lexo: F3 → значение слова → «+ в Lexo» → outbox → конец сессии.
Отчёт, картинки (строка перевода, режим слов, что ушло в OCR) и логи последней сборки лежат
в артефакте `selftest` и в ветке `ci-results` (`git fetch origin ci-results`).

**Релиз.** Подними `__version__` в `src/lexoplay/__init__.py` (и `version` в `pyproject.toml`),
положи заметки в `packaging/notes/v<версия>.md` и запушь в `main`: CI сам создаст тег и Release
с `LexoPlay.exe`. Та же версия второй раз не выпускается.

## Как устроено

```
src/lexoplay/
  geometry.py     нормализованные координаты ↔ экран, Magpie (fit_aspect), где рисовать строку
  preprocess.py   обрезка, увеличение, инверсия тёмного фона; слепки для «реплика сменилась»
  textproc.py     строки OCR → реплика: переносы, имя говорящего
  dedupe.py       память реплик: повторный F2 бесплатно + контекст для перевода
  translate.py    перевод через Lexo (LexoTranslator) или своим ключом (AnthropicTranslator)
  pipeline.py     F2 целиком: стабильный кадр → OCR → реплика → перевод; scan для F3 (без Qt и Windows)
  lexo.py         клиент /desktop/*: привязка, перевод, значение слова, карточки, ошибки сервера
  outbox.py       очередь слов и концов сессий: повторы 2, 4, 8… с, пауза при отвязке
  session.py      игровые сессии: конец по закрытию игры (5 мин на перезапуск), простою 30 мин, выходу
  vocab.py        слова из Lexo для жёлтой подсветки
  words.py        служебные слова, формы слова (did → do), обрезка пунктуации
  wordmode.py     F3 без Qt: какие слова кликабельны, фраза до 5 слов, где поставить карточку
  store.py        SQLite: профили игр, outbox, vocab
  bg.py           фоновый поток с asyncio: захват, OCR, сеть
  app.py          трей, хоткеи, события окон, F2, F3, связка с Lexo
  win/            ctypes: окна и Magpie, PrintWindow/mss, winrt OCR, RegisterHotKey, WinEventHook
  games.py        что считать игрой (браузеры и лаунчеры нет), список окон
  report.py       zip-отчёт: лог, настройки, игры, кадры отладки (без секретов)
  ui/             окно LexoPlay (main_window), оверлей, режим слов, выделение области, выбор окна, клавиши
```

Поток Qt не делает ничего долгого: всё тяжёлое в `BackgroundLoop`, результаты возвращаются
сигналами. WinRT живёт только в фоновом потоке (MTA), чтобы не спорить с Qt (STA).

Иконки окна нарисованы в духе Lucide (ISC). Шрифт окна системный: Segoe UI Variable (Windows 11) или Segoe UI.
